# Wave 3 · تصحيحات قصة المستخدم (5 تشرين الثاني 2026)

**الحالة:** مسودة خطة غير معتمدة. كُتبت من مراجعة قصة المستخدم بتاريخ 5/11، ومن قراءة الكود على `main`. يبقى `contracts.md` و`decisions.md` مرجع الحقيقة. البنود الموسومة **[contract]** لا يُكتب لها كود قبل توقيع قرارها (D-number).

**طريقة التنفيذ** كما في Wave 2:
- كل بند يُنفّذ بأمر `/lifecycle X-NN` وعلى فرع خاص به (`wave3/X-NN-slug`).
- الاختبار يُكتب أولاً.
- كل بند ينتهي بملف تسليم في `wave3/handoffs/`.

**الحجم:** S = نصف يوم أو أقل · M = يوم إلى يومين · L = 3 إلى 5 أيام.
