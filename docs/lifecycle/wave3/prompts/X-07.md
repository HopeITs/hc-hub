## Rules
- A `public int $year` on the panel (default `today()->year`), `#[Url]` only if sibling panels keep state in the URL; otherwise plain property.
- `months()` returns the 12 month starts of `$year`. Every query in the panel reads its period window from `months()` (one definition; no second date range).
- ‹ ›: `previousYear()` / `nextYear()`; next is disabled beyond the current year. The year label sits between them, LTR-isolated.
- Late marker: a project with a report from **before** `$year`'s January that is still not submitted keeps its late marker on the row (same rule the panel uses today for "late"); say in the plan which query feeds it.
- Months after today in the current year render as empty future cells, not as missing reports.
