# X-06 · "My projects" task scope for project owners · Dev 2 · S (½–1 day) · 1 slice · needs D-73

## Goal
A project manager sees the tasks of their own projects. The desk Tasks panel and the department-tasks page get a **My projects** scope next to `department`: tasks on projects the user answers for (`User::ownedProjectIds()`). It is offered to project owners and department managers.

## [contract] · authorised by D-73
- `§12.2`: scope value `projects` ("My projects") = tasks whose `project_id` is in `User::ownedProjectIds()`. Offered when `User::canSeeProjectTasks()` = `ownedOpenProjectIds() !== []` or `canSeeDepartmentTasks()`.
- `canSeeDepartmentTasks()` is unchanged (the `department` scope stays job-level only). The department-tasks page opens for `canSeeDepartmentTasks() || canSeeProjectTasks()` and shows only the scopes the user may use.
