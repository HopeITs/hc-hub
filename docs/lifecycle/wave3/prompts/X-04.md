## Rules
- Add the permission to the catalog the seeder and `permissions:sync` read; add `'proposals.approve'` to the GM exclusion list.
- `permissions:sync` never revokes, so add a one-off migration `revoke_proposals_approve_from_non_pr_roles`: removes `proposals.approve` from every role except `Public Relations Manager` (and Super Admin if it is stored). Idempotent; `down()` is a no-op with a comment.
- UI: the Approve action and the approval modal render only when `@can('approve', $proposal)`; the Livewire method authorizes again.
- Update the policy docblock (it says "There is no proposals.approve permission").
