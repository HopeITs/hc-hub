### Schema
`projects.host_center_id` unsigned big int null, after `center_id`, index `projects_host_center_id_index`, **no FK** (HR id). No backfill.

### `App\Models\Project`
```php
// @property int|null $host_center_id   (in #[Fillable])
public function hostCenter(): ?HrCenter;     // HrCenter::remembered(host_center_id); no relation, call as a method
public function isHosted(): bool;            // host_center_id !== null
public function locationLabel(): string;     // center name | «{city} · hosted by {host}» (projects.hosted_location) | city alone (legacy); needs `city` loaded
public static function openProjectFor(?int $centerId, int $cityId, int $programId, ?int $exceptId = null): ?Project;
```
- `openProjectFor()`: `center_id = ?` when a center is given, else `center_id IS NULL AND city_id = ?`; still locks the `programs` row first, so call it inside the writing transaction. Selects `id, slug, name, status, city_id, center_id, host_center_id, program_id`.
- Callers moved: `SaveProject`, `RestoreProject`, `ReopenProjectAsDraft`, `CloneProposalForRenewal`, `ManagesProjectForm::existingPairProject()`. None is left on the old signature.

### `App\Actions\Projects\SaveProject::handle(?Project $existing, array $data, User $actor): Project`
`$data` keys now read: `name?, description?, startDate?, endDate?, targetBeneficiaries?, targetMen?, targetWomen?, targetBoys?, targetGirls?, centerId?, hostCenterId?, cityId?, programId?, userId?, sectorIds?`.
- `centerId`: `required_without:hostCenterId` on create, and on edit once the project has a center or a host (`projects.choose_center_or_host`); must be an active `HrCenter` (the edited project's own inactive center stays allowed).
- `hostCenterId`: nullable; refused beside a center (`projects.choose_center_or_host`, or `projects.cannot_host_own_center` when it is the same id); must be an **active** `HrCenter` (`projects.choose_the_center`).
- `cityId`: required when a host is sent without a center (`projects.choose_the_city`); must exist in HR `cities`. Ignored whenever a center is sent: the city is always the center's.
- Writes: `center_id`, `host_center_id` (**null whenever a center is set**), `city_id` = center's city | input | kept (legacy rows with neither value stay saveable when the edit does not touch placement).
- Default name: «Program — Center», the host center standing in for a hosted project.
- Duplicate rule: checked when `center_id` **or** `host_center_id` is set and (create, or `center_id/host_center_id/city_id/program_id` dirty); error on `centerId` for a centered project, on `hostCenterId` for a hosted one, message `projects.open_project_exists`.
