## Delivered contracts (slice 2: the pause rule, D-66)

### Definitions (one place each)
- `Project::isPaused(): bool`: the project's **own** center exists and HR has deactivated it (builds on `hasInactiveCenter()`). A hosted project is never paused by its host; a project with no center is never paused; HR down → not paused (fails open).
- `Project::scopePaused()` / `Project::scopeNotPaused()`: SQL through the remembered inactive center ids (`whereIn` / `whereNull OR whereNotIn` on `projects.center_id`), no `whereHas` across connections. `Project::pausedIds(): list<int>` (one query).
- `HrCenter::inactiveIds(): list<int>` from the remembered lookup; `HrCenter::forgetRememberedLookup()` (new on `RemembersHrLookup`) drops the lookup, for code or tests that change HR data mid-request.
- `Task::isPaused(?array $pausedProjectIds = null): bool` (source is the project, or a milestone of it; needs `source` loaded, milestones with `project_id`) and `Task::scopeNotPaused()` (excludes `source_type = project` and `milestone` rows of paused projects; program-, proposal- and annual-plan tasks are never paused). `Indicator::scopeNotPaused()` (by `indicators.project_id`).

### Scanner exclusion list
Paused projects are left out of, each by a single `->notPaused()` (or the milestone join condition):
- `DeadlineCatalog::items()`: project and milestone **tasks**, **milestones**, the **project** end-date item. This covers `DueSoonScanner`, `OverdueScanner`, `EscalationScanner` and the digests, which read the catalog.
- `ProjectDatesScanner` (started / ended), `StalledScanner` (tasks), `DataGapScanner` (active-project gaps and `programsWithOpenProjects()`), `OffTrackIndicatorScanner` (indicators of the project).

Kept on purpose: the deadline items `report` (legacy), `monthly_report` and `donor_report`; the stalled **report** rule; `OnHoldReminderScanner`; proposal- and transfer-level items; department tasks of a proposal plan. `TaskKind` is unchanged: it has no `Report` case, so "report tasks" are read as these report deadline items (Q1, awaiting Dev 1's confirmation).
