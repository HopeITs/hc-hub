### Form (`ManagesProjectForm`, `pages/projects/_index-project-modal.blade.php`)
- Create dialog title and primary button: `projects.add_center` («Add center» / «إضافة مركز»). Edit keeps `projects.edit_project`. Page and sidebar wording is unchanged.
- Field order: **city** (`data-test="project-city-select"`, required) → **program** (`project-program-select`) → **physical center** (`project-center-select`, optional) → **host center** (`host-center-select`, only while no center is chosen, required then) → **owner** (`project-owner-select`) → `x-projects.sector-picker`.
- `#[Computed] centerOptions()`: active HR centers **of the chosen city** (plus the edited project's own center when HR deactivated it and it stands in that city); empty until a city is chosen. The select is disabled and the wrapper carries `data-center-select-disabled`; helper `projects.choose_the_city_first` (no city yet) or `projects.no_centers_in_city`.
- `#[Computed] hostCenterOptions()`: every active center **outside** the chosen city. `#[Computed] placementCityOptions()` replaces `hostCityOptions()` (active HR cities, always shown). `#[Computed] nameDefaultLabels()` feeds the name default.
- Hooks: `updatedCityId()` drops a chosen center that does not stand in the new city and a host that does; `updatedCenterId()` clears the host (the city stays); the edit dialog now always fills `cityId` (`project.city_id`).
- Name default is **client-side only**: the modal root (`data-name-default`, `x-effect="syncName()"`) builds «{Program} — {Center}», or «{Program} — {City}» without a center, from `nameDefaultLabels`, and writes it only while the name is empty or still the last proposal. `proposeName()` / `$proposedName` are removed; the server never writes a name except `SaveProject`'s existing blank-name fallback (unchanged, still «Program — Center», the host center standing in for a hosted project).
- `SaveProject` is **unchanged**; the form sends `cityId`, `centerId`, `hostCenterId`.
