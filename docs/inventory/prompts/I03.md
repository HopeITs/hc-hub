# I03 · Enums, categories and seeder

Phase P0 · Model: sonnet · Group A · Needs: I01 · Decisions: D6

## Goal
All inventory enums exist with translated labels, and `inventory_categories` is seeded with the organisation's real
item list, so every later task and the importer share one vocabulary.

## Sources of truth
1. `docs/inventory/contracts.md §1, §2 (inventory_categories)`.
2. An existing enum with labels, e.g. `modules/Hr/Enums/EmployeeStatus.php`, and `lang/{en,ar}/enums.php`.
3. `.ai/rules/enums.md`, `views-enums.md`, `database-migrations.md`, `migrations.md`, `feature.md`, `database-seeders.md`, `seeders.md`, `factories.md`, `models.md`.

## Start state
- I01 merged. No `inventory_*` table exists.

## Rules
- Enums exactly as in the contract (cases, values, helper methods). Labels via the same `label()` mechanism the Hr enums use.
- Category seed list (name_en · group · requires_serial · has_specs). Arabic names are yours to write correctly:
  - **it**: Laptop ✔✔ · Desktop PC ✔✔ · All-in-One PC ✔✔ · Monitor ✔ · Printer ✔ · Scanner ✔ · Projector ✔ · Tablet ✔ · Mobile Phone ✔ · UPS ✔ · External Hard Drive ✔ · Server ✔✔
  - **network**: Router ✔ · Switch ✔ · Access Point ✔ · Hub · Modem ✔ · Network Cabinet
  - **security**: Security Camera ✔ · DVR / NVR ✔ · Fingerprint Device ✔
  - **media**: Camera Body ✔ · Lens ✔ · Light · Microphone · Audio Recorder ✔ · Gimbal ✔ · Tripod / Stand · Camera Bag · Drone ✔
  - **accessory**: Keyboard · Mouse · Headset · Webcam · Speaker · Charger / Adapter · Docking Station · Flash Drive
  - **other**: Other
- The seeder upserts on `slug`, so it is safe to run twice and never deletes a category.

## Build order
1. Tests first: `tests/Feature/Inventory/CategorySeederTest.php` (seeds expected count; second run adds nothing;
   every enum case has an en and an ar label) — and keep `tests/Feature/DatabaseEncodingTest.php` green.
2. Enums + lang entries.
3. Migration `create_inventory_categories_table`, model `Category` (`#[Fillable]`, `casts()`), factory, seeder
   `InventoryCategorySeeder` (call it from the place Hr's reference seeders are called).

## Definition of done
- Both test files pass (paste the line). `php artisan migrate:rollback --step=1` works locally.
- Handoff lists every enum FQCN with its cases and the category slugs.

## Stop and escalate
- An enum label mechanism differs between Hr and Tracking: ask which to follow.

## Do not
- Create the assets table, a categories admin page, or change an enum value from the contract.
