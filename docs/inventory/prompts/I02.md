# I02 · Permissions and role baselines

Phase P0 · Model: sonnet · Group A · Needs: I01 · Decisions: D9 + open questions in `decisions.md`

## Goal
The full `inventory` permission group exists in the catalog, is synced by `permissions:sync`, and each existing role
has a sensible baseline, so later tasks only reference abilities and never add permissions.

## Sources of truth
1. `docs/inventory/contracts.md §4`.
2. `config/access-control.php` (groups, role baselines — read how `checklists` and `hr` groups are declared),
   the `permissions:sync` command, `app/Support/Access/AccessScope.php`.
3. `.ai/rules/policies.md`, `commands-seeders.md`, `enums.md`, and the existing catalog test (search `tests/` for `access-control`).
4. Handoff `I01.md`.

## Start state
- I01 merged: `inventory.view-own` is the only key in the group.

## Rules
- Baselines: every employee role → `view-own`. City IT / IT officer roles → `view-city, manage, assign, transfer,
  dispose, audit, sims.manage, licenses.manage`. IT manager / admin → all of the above + `view-all, import`.
  General Manager → `view-all, approve-disposal`. HR roles → `view-all` (read only, for the profile tab).
  Use the role names that exist in the config; do not invent roles. Where no matching role exists, leave it out and list it in the handoff.
- `approve-disposal` is never in the same baseline as `dispose` except for admin.

## Build order
1. Test first: extend the catalog test (or add `tests/Feature/Inventory/PermissionCatalogTest.php`) — all 12 keys
   exist after `permissions:sync`; the baseline matrix above holds; an employee role has only `view-own`.
2. Edit `config/access-control.php`.
3. Run `php artisan permissions:sync --no-interaction` locally and paste the output in the handoff.

## Definition of done
- The catalog test passes (paste the line). `permissions:sync` is idempotent (second run changes nothing).
- Handoff contains the final role → permission matrix as a table.

## Stop and escalate
- A baseline would give a role an ability the open questions in `decisions.md` leave undecided: keep the default written there and flag it.

## Do not
- Write policies (I04 onward) or touch any role's non-inventory permissions.
