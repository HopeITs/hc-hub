# I20 · UAT, user guide and sheet retirement

Phase P7 · Owner: developer + IT team (agent assists: sonnet) · Needs: I19 = go

## Goal
The IT team works in the hub, not in the sheet: they have tested the real flows with real data, a short bilingual
guide exists, and the Google Sheet is read-only with its secrets removed.

## Agent part
1. Write UAT scenarios as a checklist in `docs/inventory/uat.md` — one per role, plain words, each with expected result:
   - IT officer (city): register a device · assign to an employee · employee confirms · take it back damaged ·
     send 3 devices to another city · stock-take a center.
   - Employee: see my equipment · confirm receipt · report a problem.
   - HR: onboarding delivery with a device · profile equipment tab · offboarding blocked until return · print clearance form.
   - General Manager: approve a sale, reject a disposal.
   - IT manager: overview numbers match a known city · find a device by serial from global search · licence expiry list.
2. Run the scenarios yourself on local with seeded data through the browser preview, fix nothing, and record pass/fail with evidence in the same file.
3. Write the user-guide section (en + ar) where the hub's existing guide lives (find it; if none exists, ask before creating a new docs folder).

## Human part (developer / IT — list as a checklist in the handoff, do not perform)
- Run UAT with the IT team on staging; log findings as ClickUp subtasks under P7.
- Production import per the I11 run book; reconcile counts.
- Google Sheet: restrict sharing to named accounts, set to view-only, add a banner row "moved to the hub on <date>".
- Rotate every password that was stored in the sheet (DVRs, e-mail accounts) and move them to the password manager — independent of go-live.

## Definition of done
- `docs/inventory/uat.md` complete with local results; guide section written; handoff contains the human checklist with owners and dates left blank for the developer.

## Do not
- Change sheet sharing, rotate passwords, or run anything on staging/production from an agent session.
