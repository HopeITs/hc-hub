# I16 · Software licences

Phase P5 · Model: sonnet · Group H · Needs: I04 · Decisions: D3, D6

## Goal
Antivirus and other software licences (the "Kasper" tab, about 62) are tracked with their expiry and the device or
person using them, and the licence key is the one secret the module stores — encrypted, and revealed only on purpose.

## Sources of truth
1. `docs/inventory/contracts.md §2 (inventory_licenses), §4 (`LicensePolicy::viewKey`), §7, §8, §9`.
2. Laravel's built-in `encrypted` cast (confirm with `search-docs`); `modules/Hr/Casts/EncryptedSalary.php` to see how
   this codebase treats an encrypted column (hidden, never selected in lists).
3. `.ai/rules/pages.md`, `ui.md`, `models.md`, `database-migrations.md`, `commands.md`. Skill `laravel-security`. Handoffs `I04.md`, `I05.md`.

## Start state
- `inventory.licenses.manage` exists; `APP_KEY` is set in the test environment.

## Rules
- `license_key`: `text` column, `encrypted` cast, in `$hidden`, never in a list query (`select` without it), never in
  CSV export, activity log, notification, exception message or search index.
- Reveal: an explicit "Show key" action per row, authorised by `viewKey`, that returns the key for that one record,
  records an activity entry "key revealed by X", and is rate-limited. The key is not sent to the browser before the click.
- Register filters: product, type, expiry window (expired / ≤ 30 days / later), program, city, "still needed". Link to
  asset (`asset_id`) and/or employee.
- `inventory:import-licenses {csv} --dry-run`: idempotent on (product, key hash kept in memory only — do not add a
  plaintext or reversible hash column; idempotency may use `legacy_source/legacy_row` columns added in this migration).
  Fixtures use invented keys.
- The expiry alert scanner itself is I18; expose a `License::expiringWithin(int $days)` scope for it here.

## Build order
1. Tests first, `tests/Feature/Inventory/Licenses/`: `LicenseSecrecyTest` (raw DB value is not the plaintext; key
   absent from index HTML, export and model `toArray()`; reveal returns it for an authorised user, 403 otherwise,
   and writes an activity entry), `LicenseRegisterTest` (403, scope, filters, query count), `LicenseImportTest`.
2. Migration, model, factory, `LicensePolicy`, page `inventory.licenses.index` + modal, the command.

## Definition of done
- The three test files pass (paste the line); rollback works. Handoff gives dry-run counts only (per product / expired).

## Stop and escalate
- Anyone asks to store other secrets (DVR, e-mail, Wi-Fi passwords) "since the cast is there": that is D3 — refuse and report.

## Do not
- Log or display keys anywhere else, add a generic "secrets" table, or write a custom encryption cast.
