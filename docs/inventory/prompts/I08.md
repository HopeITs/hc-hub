# I08 · My equipment and confirm receipt

Phase P2 · Model: sonnet · Group E · Needs: I07 · Decisions: D9

## Goal
Every employee has one page listing what the organisation has handed them, confirms receipt with one click, and can
report a problem. This is the page that replaces "nobody signs for what they receive".

## Sources of truth
1. `docs/inventory/contracts.md §3, §5, §7, §8`.
2. A self-service Hr page for the logged-in employee (e.g. checklists "view-own" page) for layout and for how the user's employee is resolved.
3. `.ai/rules/pages.md`, `ui.md`, `views.md`, `notifications.md`, `views-components-notifications.md`.
4. Handoff `I07.md`.

## Start state
- `AssignAsset`, `AcknowledgeCustody`, `ReportAssetCondition` and the custody notification exist.

## Rules
- The list is `Asset::heldBy($employee)` for the authenticated user's employee only; there is no employee id in the URL or in a public Livewire property.
- Two sections: "Waiting for your confirmation" (open, unacknowledged) on top, then "In your custody". A collapsed "Returned" history below.
- Confirm calls `AcknowledgeCustody` with a custody loaded through the employee's own custodies (`whereKey`), never by raw id.
- "Report a problem" (broken / missing + note) calls `ReportAssetCondition`; `CustodyPolicy`/`AssetPolicy::report` allows the holder for their own open custody.
- A user with no linked employee sees a clear empty state, not an error.
- The custody notification links to this page. Price, invoice and other holders' names are never shown here.

## Build order
1. Test first: `tests/Feature/Inventory/MyEquipmentTest.php` — sees only own items; cannot acknowledge another
   employee's custody (forged id → 404/403); acknowledge sets the timestamp once; report problem changes status and
   keeps the custody open; user without employee → empty state; fixed query count.
2. Route `inventory.mine`, page `pages/mine/⚡index.blade.php`, nav destination visible to every `view-own` user.
3. Wire the notification's action URL.

## Definition of done
- The test file passes (paste the line). Page checked at 360 px, en + ar.

## Stop and escalate
- A user can be linked to more than one employee record.

## Do not
- Let the employee return, transfer or edit an asset; add e-signature or file upload.
