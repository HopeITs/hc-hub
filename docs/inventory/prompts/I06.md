# I06 · Asset create, edit and show pages

Phase P1 · Model: sonnet · Group C · Needs: I05 · Decisions: D4, D6 · Slices: 2

## Goal
An IT officer registers a device in under a minute and gets a single page per device that tells its whole story:
what it is, where it is, who holds it, plus notes and files (invoice, photos).

## Sources of truth
1. `docs/inventory/contracts.md §2, §3, §5, §7`.
2. A detail page using `x-ui.detail-header` with tabs/panels, `<x-notes.record>`, `<x-ui.form-file>` + `SecureUpload` + `app/Models/Media.php`.
3. `.ai/rules/pages.md`, `ui.md`, `js-views-components-ui.md` (modal + form-section), `views.md`, `flux.md`, `activity.md`.
4. Skills: `livewire-development`, `fluxui-development`. Handoffs `I04.md`, `I05.md`.

## Start state
- The index page lists assets; `CreateAsset` / `UpdateAsset` exist.

## Slice 1 — create and edit
- One form component shared by create and edit (Flux modal or page — follow what sibling registers do).
- Fields: category (drives "serial required" and the specs block), brand, model, serial, condition, city, center,
  program, purchased_at, entered_at, invoice_number, purchase_price + currency (only with `manage`), notes.
- The tag is shown read-only after creation; city/center are editable **only on create** (later moves are transfers).
- Validation in the page, writing through the Actions. Duplicate serial shows a link to the existing asset.
- Tests `tests/Feature/Inventory/Assets/AssetFormTest.php`: create happy path (tag generated); serial required by
  category; out-of-city create → 403; edit cannot change city/status even with a forged property; 403 without `manage`.

## Slice 2 — show page
- Header: tag, category, status badge, holder. Panels: Details + specs · Custody history (empty state until I07) ·
  Notes (`<x-notes.record :subject="$asset">`) · Files (encrypted media: invoice, photos) · Activity.
- An actions menu with slots later tasks fill (assign/return I07 · transfer I12 · dispose I13). Render only "Edit" now.
- Loaded with `Asset::visibleTo($user)->findOrFail()` — a foreign id is 404.
- Tests `AssetShowTest.php`: scope (other city → 404); price hidden without `manage`; file upload stored encrypted and
  downloadable only by a user who can view the asset; fixed query count.

## Definition of done
- Both test files pass (paste the line). Handoff names the action-menu slot and the custody-panel partial for I07/I12/I13.

## Stop and escalate
- `Media` / `SecureUpload` cannot attach to a model outside `App\Models` without change.

## Do not
- Add assign/return/transfer/dispose buttons, a delete button (assets are retired through disposal), or QR/barcode printing.
