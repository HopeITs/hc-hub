# I17 · Hub integration: desk, work items, timeline, search

Phase P6 · Model: sonnet · Group I · Needs: I08, I12, I13 · Decisions: D1, D6

## Goal
Inventory stops being a separate corner: what needs my action shows up on my desk, devices are found from the global
search, and custody events appear on the employee's timeline — all through `ModuleRegistry`, with no edit to shared hub code.

## Sources of truth
1. `app/Support/Modules/ModuleRegistry.php` and every contract in `app/Support/Modules/Contracts/*Source.php`.
2. How Hr registers each one: `modules/Hr/HrServiceProvider.php` and `modules/Hr/Support/Desk/**`.
3. `docs/inventory/contracts.md §3, §7, §8`.
4. `.ai/rules/desk.md`, `providers.md`, `app.md`, `activity.md`. Handoffs `I08.md`, `I12.md`, `I13.md`.

## Start state
- Custody, transfers and disposals exist with their pages.

## Rules
- **Work items** (each visible only to the user who can act, each linking to the page where they act):
  my unconfirmed handovers (holder) · incoming transfers InTransit to my city (`inventory.transfer`) ·
  disposals pending my decision (`inventory.approve-disposal`, not my own requests) · open audit in my city (`inventory.audit`).
- **Desk panel**: for IT roles — counts per status in my scope + the three queues above; for other employees — "my equipment" summary. One query set, cached per request.
- **Search**: assets by tag / serial / brand / model, through `Asset::visibleTo`; SIM lines by number with `sims.manage`. Licence keys are never searchable.
- **Timeline**: custody assigned / returned on the Employee subject. **Subject links**: Employee → equipment tab; Center → assets filtered by center.
- Every source reuses existing scopes and Actions' data; no rule is redefined here.

## Build order

   disappears after the action), `InventorySearchTest` (scope, no key leakage), `InventoryDeskPanelTest` (role
