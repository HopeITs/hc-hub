# I01 · Module scaffold

Phase P0 · Model: sonnet · Group A · Needs: — · Decisions: D1, D6

## Goal
A new empty module `modules/Inventory` exists and is wired into the hub exactly like `modules/Hr`. A permitted user
opens `/inventory` and sees an empty, translated page inside the app shell with an "Inventory" entry in the side nav;
anyone else gets 403. Nothing else is built here.

## Sources of truth
1. `docs/inventory/contracts.md` §4, §7 · `docs/inventory/AGENT.md §2`.
2. `modules/Hr/HrServiceProvider.php` (the pattern to copy), `bootstrap/providers.php`, `composer.json` (psr-4 `Modules\\`).
3. `app/Support/Modules/ModuleRegistry.php`, `app/Support/Modules/Contracts/DestinationSource.php`,
   `modules/Hr/Support/Desk/HrDestinations.php`, `resources/views/components/desk/side-nav.blade.php`.
4. `.ai/rules/providers.md`, `routes.md`, `desk.md`, `views.md`, `views-enums.md`, `pages.md`.

## Start state
- `main` is clean and `modules/Inventory` does not exist.
- `php artisan route:list --path=inventory` returns nothing.

## Build order
1. Test first: `tests/Feature/Inventory/ModuleScaffoldTest.php` — permitted user gets 200 on `inventory.overview`;
   user without the permission gets 403; guest is redirected; the side nav shows the entry only when permitted.
   The permission `inventory.view-own` is not in the catalog until I02: add only that one key to the `inventory` group
   now, so the test is real (I02 completes the group).
2. `InventoryServiceProvider`: migrations path, `loadViewsFrom(..., 'inventory')`, Livewire namespace `inventory`,
   area routes loader (same middleware stack as Hr), `ModuleRegistry` destination. Register it in `bootstrap/providers.php`.
3. `modules/Inventory/routes/overview.php`, the page `pages/overview/⚡index.blade.php` (page header + empty state from `x-ui.*`).
4. `modules/Inventory/Support/Desk/InventoryDestinations.php`.
5. `lang/{en,ar}/inventory.php` with the keys used so far.

## Quality bar (this task)
- The provider has no logic beyond wiring; each concern is one small private method, as in Hr.
- No hard-coded strings in the view; Arabic labels are real Arabic, not transliteration.

## Definition of done
- `php -d memory_limit=1536M vendor/bin/pest --compact tests/Feature/Inventory/ModuleScaffoldTest.php` passes (paste the line).
- `php artisan route:list --path=inventory` shows `inventory.overview`.
- Pint clean. Handoff `docs/inventory/handoffs/I01.md` lists the provider method names later tasks extend.

## Stop and escalate
- Hr wires something through a mechanism you cannot reuse without editing Hr or `app/` code.
- The side nav needs a new group or icon that does not exist.

## Do not
- Create models, migrations, enums or any page other than the overview shell.
- Add a composer/npm dependency or a new base folder outside `modules/Inventory`.
