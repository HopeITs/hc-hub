# قصة المستخدم · Media Team (الإعلام)

## من أنا وماذا أريد
أنفّذ المخرجات الإعلامية التي يحتاجها كل Proposal ومشروع، مثل الصور والقصص والمواد المطلوبة للممول، وأسلّمها في وقتها.

## أين أبدأ
**الـ Desk:** لوحة Tasks، والإشعارات.
ومن الـ Sidebar: **My Workspace**، وفيها Tasks وDepartment Tasks.

## السيناريو خطوة بخطوة
1. عند التخطيط للـ Proposal يضيف الـ PR **مهام قسم الإعلام**: العنوان، والموعد، والـ Milestone المرتبطة.
2. يصلني إشعار **مهمة قسم جديدة**، ثم تذكير قبل الموعد، ثم تنبيه إذا تأخرت.
3. أفتح المهمة، فأرى التفاصيل والـ Proposal المرتبط، **بدون أي مبالغ مالية**.
4. أنفّذ العمل، وأرفع الملفات، ثم أضغط **تسليم**.
5. إذا أعاد الطالب المهمة يصلني إشعار مهم مع السبب، فأعدّل وأسلّم من جديد.
6. قد تُسند لي **مهمة تقرير** (Report task): تظهر في Tasks مع رابط التقرير، وتُغلق عند تعليم التقرير «مُرسل».

## ما أضيفه
- الملفات الإعلامية.
- تسليم المهام.
- قائمة To-do الشخصية.

## ما لا أفعله
- رؤية الأموال.
- تعديل الـ Proposal أو الـ Targets.
