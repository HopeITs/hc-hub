# قصة المستخدم · General Manager (المدير العام / CEO)

> المدير العام **يراجع ويوافق على الممولين الجدد**، لكنه **لا يعتمد الـ Proposal**، فالاعتماد للـ PR Manager.
> العلامة ⏳ تعني جزءاً مخططاً في Wave 3 ولم يُنفَّذ بعد.

## من أنا وماذا أريد
أريد صورة كاملة عن المؤسسة، وأن أقرر في النقاط الحساسة: من نتعامل معه من الممولين، ورأيي في الطلبات المهمة.

## أين أبدأ
**الـ Desk:** طلبات الممولين المعلّقة، وملخصات المشاريع والتقارير، والإشعارات (أنا ضمن الإشراف على معظم الأحداث).

## السيناريو خطوة بخطوة

### 1. الموافقة على ممول جديد
- عندما يضيف موظف PR ممولاً من نموذج الـ Proposal، يصلني إشعار **طلب ممول**.
- أفتح **Donors**، فأجد الطلبات المعلّقة. **أوافق** أو **أرفض**.
- يبقى الـ Proposal المرتبط غير قابل للحفظ حتى أوافق.

### 2. المراجعة
- أنا خانة «CEO» بين المراجعين، فتصلني مهمة مراجعة للـ Concept note والـ Proposal عند اختياري.
- أكتب رأيي. القرار النهائي بعد ذلك للـ PR Manager.

### 3. المتابعة
- أرى كل الصفحات: المشاريع، والـ Proposals، والاتفاقيات، والتحويلات، ومصفوفة التقارير الشهرية، وتقارير الممول.
- أتابع التأخيرات: تقارير شهرية متأخرة، ودفعات متأخرة، ومهام أقسام متأخرة.
- تصلني طلبات إعادة فتح التقارير الشهرية **فقط إذا لم يوجد** من يقرر فيها (لا مدير MEAL ولا PR Manager).

### 4. التصحيح
- أصحّح حالة نهائية خاطئة لـ Proposal (`rejected` أو `completed`) مع سبب.

## ما لا أفعله
- ⏳ اعتماد الـ Proposal (`approved`)، فهذا للـ PR Manager. اليوم ما زال الزر يظهر لي.
- اعتماد التقارير الشهرية أو تعبئتها.
- تحديد الـ Targets، فهذا للـ MEAL.
