# قصص المستخدم حسب الدور

هذه القصص مبنية على الكود الحالي، وعلى تصحيحات مراجعة 5 تشرين الثاني ([خطة Wave 3](../../lifecycle/wave3/README.ar.md)).
العلامة ⏳ تعني جزءاً مخططاً ولم يُنفَّذ بعد.

## تعريفان مهمان
- **عند فريق الـ PR:** الـ Proposal هو «المشروع»، وله ممول أساسي واحد (وقد يوجد ممول وسيط) وتقرير ختامي واحد.
- **عند باقي المؤسسة:** المشروع = **برنامج × محافظة**، والمراكز مواقعه. التقرير الشهري واحد لكل مشروع لكل شهر، حتى لو موّله أكثر من ممول.

## الرحلة باختصار
```
Proposal (Concept note أو Draft) → مراجعة داخلية → إرسال للممول → اعتماد (PR Manager)
→ إنشاء المشاريع تلقائياً → إقرار المالك → تأكيد قالب التقرير (MEAL) → active
→ تقارير شهرية (المدير يرسل، MEAL يعتمد) → تقارير الممول → تمديد عند الحاجة → تقرير ختامي → completed
```
