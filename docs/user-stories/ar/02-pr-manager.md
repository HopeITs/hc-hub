# قصة المستخدم · Public Relations Manager (مدير المشاريع وجمع التمويل)

> اسم الدور في النظام هو `Public Relations Manager`. هو **صاحب قرار اعتماد الـ Proposal**.
> العلامة ⏳ تعني جزءاً مخططاً في Wave 3 ولم يُنفَّذ بعد.

## من أنا وماذا أريد
أقود فريق جمع التمويل. أراجع الطلبات، وأعتمد ما يوافق عليه الممول، وأسجّل الاتفاقيات، وأغلق المشاريع.

## أين أبدأ
**الـ Desk:** الـ Proposals التي تنتظر مراجعتي، والإشعارات، ولوحة التحويلات المتأخرة.

## السيناريو خطوة بخطوة

### 1. المراجعة
- تصلني مهمة مراجعة عندما يُرسَل Concept note أو Proposal للمراجعة، لأني خانة «مدير جمع التمويل».
- أفتح الـ Proposal، وأقرأ الـ Concept note أو الخطة، ثم إما أُعيده بسبب، أو أنقله إلى `submitted`.
- أدير المراجعين: أضيف أو أحذف مراجعاً.

### 2. الاعتماد (`approved`)
- عندما يوافق الممول أضغط **Approve**.
- **الشروط:**
  - كل صف موقع كامل: برنامج، ومسؤول تقرير، ومركز أو «جديد».
  - لا يوجد طلب برنامج معلّق.
- **ما يحدث تلقائياً:**
  - تُنشأ المشاريع (برنامج × محافظة) أو تُستعمل الموجودة، وتُربط المراكز بها.
  - يصل للـ MEAL «قالب تقرير بانتظار التأكيد».
  - يصل إشعار للمالية وللمسؤولين.
- ⏳ الاعتماد سيكون لي وحدي، فاليوم يقدر GM وFinancial أيضاً.

### 3. الاتفاقية والتحويلات
- أسجّل **Funding agreement** مرة واحدة لكل Proposal معتمد: الرقم عند الممول، والمبلغ، والأقساط.
- يولّد النظام **دفعة متوقعة لكل قسط**، وأتابع المستلَم والمتأخر مع المالية.

### 4. أثناء التنفيذ
- **التمديد:** على Proposal نشط أضغط **Extend**، وأكتب تاريخ النهاية الجديد، وسبباً، وأرفع ملف التعديل. يبقى نفس الرقم ونفس المشاريع، وتُضاف أشهر تقارير جديدة تلقائياً.
- **طلبات إعادة فتح التقارير الشهرية:** أقرر فيها إذا كانت خانة مدير الـ MEAL فارغة.
- ⏳ تنبيه عندما يقترب المشروع من نهايته ولديه رصيد متبقٍ، لأطلب التمديد.

### 5. الإغلاق
- أقبل **التقرير الختامي**: التاريخ، ومن قبِله، وملف القبول، فيصبح الـ Proposal `completed`.
- أصحّح حالة نهائية خاطئة (`rejected` أو `completed`) مع سبب.

## ما أضيفه
- قرار الاعتماد.
- الاتفاقيات والأقساط.
- التمديدات.
- قبول التقرير الختامي.
- تصحيح الحالات.
- ⏳ المراكز والبرامج والـ Sectors، مع فريقي.

## الإشعارات التي تصلني
- طلبات المراجعة.
- الاعتماد بلا اتفاقية.
- استلام الدفعات وتأخرها.
- إقرار مالك المشروع أو رفضه.
- طلبات إعادة الفتح عند غياب مدير الـ MEAL.

## ما لا أستطيعه
- اعتماد ممول جديد، فهذا للمدير العام.
- اعتماد التقارير الشهرية، فهذا للـ MEAL.
