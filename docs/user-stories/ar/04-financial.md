# قصة المستخدم · Financial (المالية)

> العلامة ⏳ تعني جزءاً مخططاً في Wave 3 ولم يُنفَّذ بعد.

## من أنا وماذا أريد
أضع الميزانيات، وأتابع الأموال المتفق عليها مع الممولين حتى تصل.

## أين أبدأ
**الـ Desk:** مهام قسم المالية، ومهام المراجعة، والتحويلات المتأخرة.
ومن الـ Sidebar: **Funding & Finance**، وفيها Proposals وFunding Agreements وTransfers وAccounts.

## السيناريو خطوة بخطوة

### 1. الميزانية في مرحلة الـ Proposal
- عندما يكون الـ Proposal في `proposal draft` أُدخل **الميزانية المطلوبة والعملة**.
- بدونها لا ينتقل الـ Proposal إلى المراجعة.
- أراجع الطلب لأني خانة «Finance manager» بين المراجعين.

### 2. مهام قسم المالية
- مهام المالية المرتبطة بالـ Proposal والـ Milestones تظهر في **Department Tasks** وفي لوحة Tasks.
- أنفّذ المهمة، وأرفع الملف، ثم أسلّمها.

### 3. بعد الاعتماد
- يصلني إشعار باعتماد الـ Proposal.
- مع الـ PR Manager أتابع **الـ Funding agreement**: المبلغ والأقساط.
- يولّد النظام **دفعة متوقعة لكل قسط**. عندما يصل المال أسجّل **الاستلام الفعلي** على الدفعة.
- تصلني تنبيهات **الدفعات المتأخرة**.
- أدير **الحسابات (Accounts)**.

### 4. التمديد
- يصلني إشعار عند تمديد Proposal: الأسماء والتواريخ فقط.

## ما أضيفه
- الميزانية والعملة.
- تسجيل الدفعات المستلَمة.
- الحسابات.
- مخرجات مهام قسم المالية.

## ما لا أفعله
- ⏳ اعتماد الـ Proposal، فهذا للـ PR Manager وحده.
- الـ Targets والتقارير الشهرية.
